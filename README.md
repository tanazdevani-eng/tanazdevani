# Kept

An iOS habit tracker where every habit has a visibility setting: Open (visible to your
Circle) or Kept (fully private). See `CLAUDE.md` for the full project brief.

- `docs/kept.html` — interactive HTML/CSS/JS mockup (source of truth for design/UX).
- `docs/keptappspec.json` — structured spec reference.
- `docs/APP_STORE_GUIDE.md` — step-by-step guide to shipping this to the App Store.
- `ios/Kept/` — the native SwiftUI implementation. See `ios/Kept/README.md` to build it.
